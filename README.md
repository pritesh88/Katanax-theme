## 📦 Installation

1. Open **VS Code**
2. Go to **Extensions** (`Ctrl+Shift+X` / `Cmd+Shift+X`)
3. Search for **KatanaX**
4. Click **Install**
5. Open Command Palette (`Ctrl+K Ctrl+T` / `Cmd+K Cmd+T`) and select your preferred variant
